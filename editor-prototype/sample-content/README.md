# Overview sample content

Six clearly labelled illustrative entries were added as separate pages. Five were published locally: two essays, two notes and a geometric sketch. One note remains an unpublished draft. The main essay includes a later dated addition and a second real publication event. All entries link into the notebook through connected ideas.

The user's existing entries and publication states were preserved. A pre-sample database and JSON backup are stored outside the served folder in `../../notebook-data/before-sample-content.sqlite3` and `../../notebook-data/before-sample-content.json`.

`loaded-samples.json` records the allocated IDs. The entries are editable in Your writing. Unpublish individual samples to remove them from the local published website without deleting their draft content. The sample draft is deliberately absent from the public catalogue.

`overview.json` is the reusable sample set. `create-samples.py` creates its original code-drawn geometric PNG and documents. `load-samples.py` loads and publishes the set through the regular server APIs. It does not duplicate or overwrite an already loaded set. These samples have not been deployed to the hosted website.
